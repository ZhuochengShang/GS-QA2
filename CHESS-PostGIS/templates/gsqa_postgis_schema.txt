Table: regions
Description: administrative region boundaries such as cities, counties, and states.
Columns:
- id: integer primary row identifier
- geometry: geography geometry in EPSG:4326
- region_name: region name
- border_type: boundary or region type
- wikidata: Wikidata id
- wikipedia: Wikipedia reference
- place: OSM place category

- admin_level: administrative level
- population: population metadata
- official_name: official name
- postal_code: postal code
- capital: capital tag
- timezone: timezone

Rules:
- Use only these five tables for GS-QA vector questions.
- geometry columns are PostGIS geography values in EPSG:4326.
- Use ST_DWithin for within-distance predicates in meters.
- Use ST_Distance for metric distances.
- Use ST_Intersects for within-region filtering.
- Cast geography to geometry only for geometry-only functions.
- Do not use raster tables, ca-suffixed tables, or PostGIS metadata tables.
